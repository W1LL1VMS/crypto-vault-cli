## Limites actuelles

La clé privée n'est pas protégée par mot de passe pour l'instant ,c'est la prochaine amélioration prévue. Le fichier entier est aussi chargé en mémoire, donc l'outil n'est pas adapté à des fichiers de plusieurs gigaoctets.

## Améliorations prévues

- Protection de la clé privée par mot de passe
- Chiffrement récursif de dossiers
- Vérification d'intégrité par hash SHA-256
- Lecture en streaming pour les gros fichiers
